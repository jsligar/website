FIRESTORE SECURITY RULES (PRODUCTION-READY)
==============================================

Copy these rules to Firebase Console → Firestore Database → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Helper function to check if user is admin
    function isAdmin() {
      return request.auth != null && request.auth.token.admin == true;
    }

    // Products collection
    match /products/{productId} {
      // Anyone can read products (public catalog)
      allow read: if true;
      // Only authenticated admins can write
      allow write: if isAdmin();
    }

    // Videos collection
    match /videos/{videoId} {
      // Anyone can read videos (public resources)
      allow read: if true;
      // Only authenticated admins can write
      allow write: if isAdmin();
    }

    // Orders collection
    match /orders/{orderId} {
      // Anyone can read (needed for order confirmation page)
      // TODO: In production, restrict to customer's own orders
      allow read: if true;

      // Anyone can create orders (for checkout)
      allow create: if true;

      // Only allow specific status updates for payment completion
      // Admins can update anything
      allow update: if isAdmin() ||
                       (request.resource.data.diff(resource.data).affectedKeys()
                        .hasOnly(['paymentStatus', 'updatedAt', 'statusHistory']));

      // Only admins can delete
      allow delete: if isAdmin();
    }

    // Customers collection
    match /customers/{customerId} {
      // Anyone can create (for checkout)
      allow create: if true;

      // Users can read their own data, admins can read all
      allow read: if isAdmin();

      // Users can update their own data, admins can update all
      allow update: if isAdmin();

      // Only admins can delete
      allow delete: if isAdmin();
    }

    // Reviews collection (NEW)
    match /reviews/{reviewId} {
      // Only approved reviews are publicly readable
      allow read: if resource.data.approved == true || isAdmin();

      // Anyone can create a review (will require approval)
      allow create: if request.resource.data.approved == false &&
                       request.resource.data.productId is string &&
                       request.resource.data.rating >= 1 &&
                       request.resource.data.rating <= 5 &&
                       request.resource.data.name is string &&
                       request.resource.data.email is string &&
                       request.resource.data.comment is string;

      // Only admins can approve/update/delete reviews
      allow update, delete: if isAdmin();
    }

    // Newsletter subscribers collection (NEW)
    match /newsletter_subscribers/{subscriberId} {
      // Only admins can read
      allow read: if isAdmin();

      // Anyone can subscribe (once per email)
      allow create: if request.resource.data.email is string &&
                       request.resource.data.email.matches('.*@.*\\..*') &&
                       request.resource.data.active == true;

      // Users can unsubscribe themselves, admins can do anything
      allow update: if isAdmin() ||
                       (request.resource.data.diff(resource.data).affectedKeys()
                        .hasOnly(['active']) && request.resource.data.active == false);

      // Only admins can delete
      allow delete: if isAdmin();
    }

    // Contact messages collection (NEW)
    match /contact_messages/{messageId} {
      // Only admins can read
      allow read: if isAdmin();

      // Anyone can create a contact message
      allow create: if request.resource.data.name is string &&
                       request.resource.data.email is string &&
                       request.resource.data.email.matches('.*@.*\\..*') &&
                       request.resource.data.subject is string &&
                       request.resource.data.message is string &&
                       request.resource.data.read == false;

      // Only admins can update/delete
      allow update, delete: if isAdmin();
    }
  }
}

SETUP INSTRUCTIONS:
===================

1. Go to Firebase Console → Firestore Database → Rules
2. Copy and paste the above rules
3. Click "Publish"

4. Set admin users with custom claims (run in Firebase Console → Authentication):
   - Go to Cloud Functions or use Firebase Admin SDK
   - Set custom claim: admin.auth().setCustomUserClaims(uid, { admin: true })

5. For better security, consider rate limiting with these options:
   - Firebase App Check (prevents abuse from non-app sources)
   - Cloud Functions with rate limiting middleware
   - Firestore security rules with quota tracking

NOTES:
======
- Reviews require admin approval before being publicly visible
- Newsletter signups are validated for email format
- Contact messages are created as unread for admin review
- All writes include basic validation
- Admin users need custom claims set in Authentication

For email notifications and better security, implement Cloud Functions (see functions/ directory).
