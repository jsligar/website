FIRESTORE SECURITY RULES
========================

Copy these rules to Firebase Console → Firestore Database → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Products collection
    match /products/{productId} {
      // Anyone can read products (public catalog)
      allow read: if true;
      // Only authenticated admins can write
      allow write: if request.auth != null;
    }

    // Videos collection
    match /videos/{videoId} {
      // Anyone can read videos (public resources)
      allow read: if true;
      // Only authenticated admins can write
      allow write: if request.auth != null;
    }

    // Orders collection
    match /orders/{orderId} {
      // Anyone can read their own orders (for payment success page)
      // Admins can read all orders
      allow read: if true;
      // Anyone can create orders (for checkout)
      allow create: if true;
      // Anyone can update orders (for payment completion)
      // TODO: Restrict this to only allow status updates after payment
      allow update: if true;
      // Only admins can delete
      allow delete: if request.auth != null;
    }

    // Customers collection
    match /customers/{customerId} {
      // Anyone can read/write for checkout process
      // TODO: Restrict to only customer's own data
      allow read, write: if true;
    }
  }
}

IMPORTANT NOTES:
- The orders rules are permissive for now to allow payment processing
- In production, you should restrict order updates to only payment status changes
- Consider adding custom claims to identify admin users vs regular customers
- For better security, implement Cloud Functions for order processing

Click "Publish" after pasting these rules.
